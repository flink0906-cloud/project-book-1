Programming is the process of developing a set of instructions that enables a computer to carry out a specific operation or solve a particular problem. These instructions are created using programming languages, which can generally be categorized as low-level, high-level, and fourth-generation languages. Low-level languages have a close relationship with the computer's hardware and machine language, whereas high-level languages are designed to be more understandable and convenient for programmers. Since computers ultimately work with machine-level instructions, translators such as compilers, interpreters, and assemblers are required to convert programs into a form that can be executed by the computer. Before implementing a solution, programmers commonly use algorithms, flowcharts, or pseudocode to organize the steps involved in solving a problem.

Errors can occur at different stages of program development and execution. A syntax error results when the programmer violates the grammatical or structural rules of a programming language. Semantic errors occur when the statements are syntactically valid but produce an incorrect meaning or logical result. Runtime errors, on the other hand, arise while the program is actually being executed. To control how instructions are carried out, programs use different control structures. Sequence executes instructions in their normal order, selection allows decisions to be made based on conditions, and iteration makes it possible to repeat a set of instructions multiple times. These structures form the basic framework for controlling the flow of most programs.

Computers use character and number encoding systems to represent information internally. At the most basic level, binary represents data using only the digits 0 and 1. Binary Coded Decimal (BCD) represents individual decimal digits using groups of binary bits, while ASCII provides a standardized method for representing commonly used letters, numbers, and symbols. Unicode extends character representation much further by supporting characters from a wide range of languages and writing systems around the world. These coding systems allow computers to store, process, and communicate numerical and textual information in a consistent digital form.

C is a general-purpose programming language that has been widely used for creating system software, applications, and other types of computer programs. A typical C program is made up of elements such as header files, functions, declarations, and executable statements. Before compilation begins, the C preprocessor handles special preprocessing instructions and incorporates required definitions or header files. Header files provide declarations and useful functions that can be used within a program. The language has its own character set and includes programming elements such as comments, identifiers, keywords, constants, variables, and data types. C also provides fundamental data types, including integer, floating-point, and character types. Constants represent values that remain unchanged during normal execution, whereas variables refer to named memory locations whose contents can be modified. Operators are used to manipulate these values and include arithmetic, relational, logical, assignment, unary, and conditional operators. Input and output functions allow programs to accept information from users and display processed results.

Decision-making and repetition are important aspects of C programming. Selection statements allow a program to choose which instructions should be executed based on particular conditions. The if statement executes a block when its condition is satisfied, while if-else provides two possible paths. Multiple conditions can be handled using an if-else-if structure, and nested statements allow one decision-making structure to be placed within another. The switch statement is useful when a program needs to select between several predefined choices. Repetition can be achieved through loops such as while, do-while, and for. C also supports arrays, which store multiple values of the same data type under a single name. A one-dimensional array represents values in a linear sequence, while a two-dimensional array can be used to represent tables or matrices, including operations such as matrix addition and subtraction. Strings are represented as sequences of characters terminated by a null character, and functions such as strlen(), strcat(), strcmp(), strrev(), strcpy(), strlwr(), and strupr() can be used to perform common string operations.
